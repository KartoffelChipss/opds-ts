    • addFacet(
          href: string,
          title: string,
          options?: { active?: boolean; numberOfItems?: number; type?: string },
      ): Facet

      Adds a facet to the group. This is a convenience method for facets linking to OPDS 2.0 feeds.

      Parameters

      • href: string

        The URL of the facet.

      • title: string

        The title of the facet (e.g. English).

      • options: { active?: boolean; numberOfItems?: number; type?: string } = {}

        numberOfItems hints at the number of publications for this facet, active marks the facet as currently selected.

      Returns Facet

      The Facet instance (for chaining).
